# Virtual Fitting - 빠른 실행 가이드

## 🚀 한 번에 실행하기

프로젝트 루트 디렉토리에서 다음 명령어를 실행하세요:

```bash
# 백엔드 실행
./start_backend.sh

# 새 터미널에서 프론트엔드 실행
cd frontend
./start_client.sh
```

## 🌐 접속 URL

- **웹앱**: http://localhost:3000
- **API 서버**: http://localhost:8000
- **API 문서**: http://localhost:8000/docs

## ✨ 새로운 기능

### 🎨 **완전히 새로워진 UI/UX**
- **모던한 그라디언트 디자인**: 보라색과 파란색 그라디언트를 사용한 세련된 디자인
- **글래스모피즘 효과**: 반투명 배경과 블러 효과로 현대적인 느낌
- **부드러운 애니메이션**: 호버 효과, 페이드인/아웃 애니메이션
- **향상된 타이포그래피**: Inter 폰트 사용, 적절한 여백과 간격
- **완벽한 반응형 디자인**: 모바일에서도 완벽하게 작동

### 📸 **OCR 사이즈 차트 자동 분석**
- **사이즈 차트 이미지 업로드**: 테이블이나 차트 형식의 이미지를 업로드하면 자동으로 사이즈 정보 추출
- **한국어/영어 지원**: pytesseract를 사용한 다국어 OCR
- **지능형 사이즈 파싱**: 
  - 가슴, 허리, 엉덩이, 어깨 등 주요 측정값 자동 추출
  - 테이블 형식 데이터 인식
  - 사이즈별 (S, M, L, XL 등) 데이터 구조화
- **신뢰도 표시**: OCR 결과의 정확도를 퍼센트로 표시
- **원본 텍스트 확인**: 추출된 원본 텍스트를 확인할 수 있는 옵션

## 📱 사용법

### 1단계: 모델 업로드
1. 전신이 잘 보이는 사진을 드래그 또는 클릭하여 업로드
2. 키를 cm 단위로 입력 (예: 170)
3. "신체 치수 계산" 버튼 클릭
4. AI가 자동으로 신체 각 부위의 치수를 계산

### 2단계: 옷 업로드 (3가지 방법)
1. 옷 사진을 업로드
2. 옷 종류 선택 (상의, 하의, 원피스, 자켓, 니트)
3. 사이즈 정보 입력 방법 선택:

   **방법 1: 치수 직접 입력**
   - 폭, 길이를 cm로 입력
   
   **방법 2: 사이즈 차트 텍스트**
   - 상세한 사이즈 정보를 텍스트로 입력
   
   **방법 3: 📷 사이즈 차트 이미지 (OCR) - NEW!**
   - 사이즈 차트가 포함된 이미지를 업로드
   - OCR이 자동으로 사이즈 정보 추출
   - 추출된 정보 확인 및 수정 가능

4. "옷 치수 분석" 버튼 클릭

### 3단계: 가상 피팅
1. 모델과 옷 정보 확인
2. **AI가 옷 종류에 따라 적절한 피팅 알고리즘 선택**
3. **MediaPipe 포즈 감지를 통해 정확한 신체 부위에 옷을 배치**
4. 예상 피팅 결과 미리보기
5. "가상 피팅 생성" 버튼 클릭
6. **AI가 현실적인 가상 피팅 이미지를 생성**

### 4단계: 결과 확인
1. 생성된 가상 피팅 이미지 확인
2. 피팅 상태와 추천사항 확인
3. 새로운 피팅 시작 또는 다른 옷으로 재시도

## 📋 필수 요구사항

### 백엔드
- Python 3.8 이상
- pip (Python 패키지 매니저)
- **Tesseract OCR** (macOS: `brew install tesseract tesseract-lang`)

### 프론트엔드
- Node.js 16 이상
- npm (Node 패키지 매니저)

## 🛠️ 문제 해결

### 포트 충돌 시
`backend/config.py`에서 포트 번호를 변경할 수 있습니다:
```python
PORT: int = 8001  # 8000에서 8001로 변경
```

### npm 권한 오류 시
```bash
sudo chown -R $(whoami) ~/.npm
npm cache clean --force
```

### Python 의존성 오류 시
```bash
cd backend
pip install --upgrade pip
pip install -r requirements.txt
```

### OCR 오류 시
Tesseract가 제대로 설치되었는지 확인:
```bash
# macOS
brew install tesseract tesseract-lang

# 설치 확인
tesseract --version
```

## 📸 권장 이미지

### 모델 사진
- 전신이 명확히 보이는 사진
- 정면을 바라보는 자세
- 팔과 다리가 벌어진 자세
- 단순한 배경
- 고해상도 이미지

### 옷 사진
- 옷이 평평하게 펼쳐진 상태
- 전체적인 형태가 잘 보이는 각도
- 깔끔한 배경
- 충분한 조명

### 사이즈 차트 이미지 (OCR용)
- **명확한 텍스트**: 인쇄된 텍스트가 선명한 이미지
- **테이블 형식**: 정리된 테이블이나 차트 형태
- **고해상도**: 최소 300DPI 이상 권장
- **단순한 배경**: 복잡한 배경이나 그림자 없는 이미지
- **대비가 좋은 이미지**: 검은 텍스트와 흰색 배경

## 🎯 주요 기능

- **AI 신체 측정**: MediaPipe를 활용한 정확한 신체 치수 계산
- **옷 분석**: 이미지 분석을 통한 옷 종류 및 치수 자동 감지
- **OCR 사이즈 차트**: 이미지에서 자동으로 사이즈 정보 추출
- **현실적인 가상 피팅**: MediaPipe 포즈 감지를 통한 정확한 신체 부위 매핑
- **옷 종류별 맞춤형 피팅**: 상의, 하의, 원피스 등에 최적화된 알고리즘
- **실시간 미리보기**: 피팅 전 예상 결과 확인
- **데이터 저장**: 업로드한 모델과 옷 정보 재사용 가능

## 🚀 OCR 사용 팁

1. **이미지 품질**: 선명하고 대비가 좋은 이미지 사용
2. **텍스트 크기**: 너무 작은 글씨는 인식률이 떨어질 수 있음
3. **배경**: 단순하고 깔끔한 배경 사용
4. **각도**: 텍스트가 기울어지지 않은 정면 이미지
5. **확인**: OCR 결과를 항상 확인하고 필요시 수정
